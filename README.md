ПРИЛОЖЕНИЕ №4: ДЕТЕКТОР ЭМОЦИЙ
========================================================================
------------------------------------------------------------------------

1. НАЗНАЧЕНИЕ ПРИЛОЖЕНИЯ
------------------------------------------------------------------------
Детектор эмоций — это приложение, которое анализирует лицо пользователя через
фронтальную камеру и пытается определить эмоциональное состояние. Для этого используется
предобученная модель TensorFlow Lite. Приложение показывает основную эмоцию и три
наиболее вероятных результата.

2. ОСНОВНЫЕ ВОЗМОЖНОСТИ
------------------------------------------------------------------------
• работа с фронтальной камерой;
• поиск лица в кадре;
• обрезка области лица;
• подготовка изображения для модели;
• запуск модели TensorFlow Lite;
• вывод главной эмоции;
• вывод top-3 результатов;
• рамка вокруг найденного лица.

3. ИНТЕРФЕЙС
------------------------------------------------------------------------
Интерфейс состоит из изображения с камеры и двух информационных панелей. Вверху
находится название приложения и статус анализа. Внизу отображается найденная эмоция и
список трёх наиболее вероятных эмоций.

Дизайн тёмный, чтобы камера и результаты анализа хорошо выделялись. На изображении лица
рисуется рамка, поэтому пользователь понимает, какую область приложение анализирует.

4. РАБОТА С КАМЕРОЙ
------------------------------------------------------------------------
Для камеры используется CameraX. Приложение запускает фронтальную камеру и получает
кадры через ImageAnalysis. Чтобы не перегружать телефон, анализ выполняется не на каждом
кадре, а с небольшой задержкой. Это делает приложение стабильнее и экономнее.

5. ПОИСК ЛИЦА
------------------------------------------------------------------------
Перед запуском модели нужно понять, где в кадре находится лицо. Для этого используется
ML Kit Face Detection. ML Kit возвращает прямоугольник лица. Если лиц несколько,
приложение выбирает самое крупное лицо, потому что оно обычно является главным объектом
в кадре.

6. РАБОТА С TENSORFLOW LITE
------------------------------------------------------------------------
После нахождения лица приложение вырезает эту область из кадра и уменьшает изображение
до размера, который нужен модели. Обычно для моделей эмоций используется формат 48 на 48
пикселей в оттенках серого. Затем изображение переводится в ByteBuffer и подаётся на
вход TFLite Interpreter.

Модель возвращает вероятности для нескольких классов эмоций. Приложение сортирует
результаты по вероятности и показывает пользователю наиболее вероятную эмоцию, а также
top-3 результата.

7. КЛАССЫ ЭМОЦИЙ
------------------------------------------------------------------------
• злость;
• отвращение;
• страх;
• радость;
• нейтральное выражение;
• грусть;
• удивление.

8. ИТОГ
------------------------------------------------------------------------
Проект показывает полный цикл интеграции машинного обучения в Android-приложение: камера
получает изображение, алгоритм находит лицо, данные подготавливаются для модели,
TensorFlow Lite выполняет предсказание, а результат выводится в интерфейс. Качество
распознавания зависит от выбранной .tflite модели, освещения и положения лица.
